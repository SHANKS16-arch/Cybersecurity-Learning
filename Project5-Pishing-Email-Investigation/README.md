# Enterprise Phishing Email Investigation

## Objective

This project documents the investigation of a phishing email using a SOC analyst workflow.

## Skills Demonstrated

- Email Header Analysis
- URL Investigation
- IOC Extraction
- WHOIS Lookup
- SPF / DKIM / DMARC Verification
- Threat Intelligence
- MITRE ATT&CK Mapping
- Incident Reporting

## Tools

- MXToolbox
- VirusTotal
- WHOIS
- URLScan
- AbuseIPDB
- Cisco Talos
- Hybrid Analysis

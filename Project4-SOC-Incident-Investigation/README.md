# Project 4 - SOC Incident Investigation

Learn how to investigate security incidents using evidence, logs, and analytical thinking from a Security Operations Center (SOC) perspective.

## Tools Used

- Terminal
- grep
- journalctl
- dmesg
- Git
- GitHub

## Skills Practiced

- Incident investigation

- SOC analyst decision making

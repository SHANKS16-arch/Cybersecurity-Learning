

# Project 3 - Linux Log Investigation

## Objective

The objective of this project is to learn how Linux stores system logs and how security analysts investigate authentication and system events using log files.

## Tools Used

- Ubuntu Linux
- Linux Terminal
- auth.log
- syslog
- journalctl
- dmesg
- grep
- sudo
- Linux pipes('|')

## Skills Practiced

- Investigated authentication logs using `auth.log`
- Investigated system events using `syslog`
- Learned how to use `journalctl` to view systemd journal logs
- Learned how to investigate kernel messages using `dmesg`
- Used `grep` to filter log entries
- Used Linux pipes (`|`) to combine commands
- Investigated USB-related kernel events
- Practiced basic SOC analyst log investigations

## Project Summary 

- Explored the `/var/log` directory.

- Practiced SOC-style log analysis and evidence-based reasoning.


## Key Takeaways

- Understood the difference between auth.log, syslog, journalctl, and dmesg.
